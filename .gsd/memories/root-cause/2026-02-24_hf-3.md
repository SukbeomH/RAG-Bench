## HF 데이터셋 로더 오류 3종 근본 원인

### 오류 1 — GENERAL: miracl/miracl-corpus 스크립트 지원 종료
- 증상: RuntimeError: Dataset scripts are no longer supported, but found miracl-corpus.py
- 원인: HuggingFace가 커스텀 로딩 스크립트 방식 데이터셋 지원 중단
- 해결: klue/klue (mrc config) streaming=True로 대체
  - context → corpus, question → query, answers.text[0] → ground_truth
  - 컬럼: title, context, guid, is_impossible, question, answers

### 오류 2 — LEGAL/BUSINESS: markers_bm subset명 불일치 + CAS 네트워크 오류
- 증상: BuilderConfig 'law' not found. Available: ['corpus', 'default', 'queries']
- 증상: CAS service error: ReqwestMiddleware Error: Request failed after 5 retries
- 원인: 데이터셋 실제 config는 'corpus'/'queries'/'default' 3개만 존재, 'law'/'finance' 등 없음
  카테고리는 _id 필드 내부에 인코딩: corpus _id = '<category> - <file> - <page>', queries _id = '<index>_<category>'
  CAS(Content Addressable Storage) 다운로드는 네트워크 오류로 5회 재시도 후 실패
- 해결: streaming=True로 3개 config 분리 로드 (CAS 우회)
  corpus: startswith('<sub> - ') 필터링
  queries: endswith('_<sub>') 필터링
  qrels: default config test split, query-id/corpus-id 교차 확인

### 오류 3 — RAGAS MetricPreset 'standard' 유효하지 않음
- 증상: ValueError: 'standard' is not a valid MetricPreset
- 원인: run_service_bench.py 390번째줄 MetricPreset('standard') 하드코딩 오류
- 유효값: ['core_only', 'full', 'reference_free', 'comprehensive']
- 해결: MetricPreset('core_only')으로 수정

### 수정 파일
- rag_bench/datasets/hf_loader.py: _load_miracl_ko → _load_klue_mrc, _load_markers_bm streaming 방식
- rag_bench/scripts/run_service_bench.py: MetricPreset('standard') → ('core_only')
