## 발견된 문제 및 교훈

### 문제 1: API 키 subprocess 미전달
- **원인**: `source .env`는 변수 설정만, `export` 없이 subprocess에 미전달
- **해결**: `set -a && source .env && set +a`
- **교훈**: 항상 `set -a` 패턴 사용, 또는 `python-dotenv` 도입 고려

### 문제 2: mlx-vlm 모델명 불일치
- **원인**: openai_compat.py의 `paddleocr-vl-1.5` vs HuggingFace `PaddlePaddle/PaddleOCR-VL-1.5`
- **해결**: `OPENSOURCE_VLM_MODEL` 환경변수로 오버라이드
- **교훈**: K8s 서버와 로컬 mlx-vlm의 모델명 체계가 다름

### 문제 3: VLM markdownify 누락 (미해결)
- **원인**: 이전에 VLM 출력을 markdownify로 정제하는 과정이 있었으나 현재 코드에 없음
- **영향**: paddleocr-vl NED 0.30 (이전 K8s 0.76 대비 크게 저하)
- **다음 단계**: markdownify 후처리 복원 필요

### 문제 4: mlx-vlm 서버 장시간 가동 불안정
- **원인**: 수일 가동 후 모든 요청에서 Internal Server Error

- **교훈**: 벤치마크 전 서버 상태 테스트 필수
