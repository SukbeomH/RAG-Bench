## 데이터 소스 분석

### H-2 Violin 데이터 소스
- `runner.reports: Dict[str, EvaluationReport]`
- `EvaluationReport.per_sample_df` — per-sample RAGAS 점수 DataFrame
  - 컬럼: `user_input`, `response`, `retrieved_contexts`, 메트릭 컬럼들
- 전략명에서 그룹 분류 (Baseline / Reranker / Contextual / Both)

### M-1 Pipeline 데이터 소스
- `ComboSpec` 인스턴스 (dense, sparse, reranker, llm_support)
- 정적 파이프라인 구조 → 데이터 불필요, `spec`만 받아 레이어 시각화

### M-3 Gantt 데이터 소스
- `run_record["strategy_timings"]` — `StrategyTiming` dict 목록
  - `label`, `build_time_s`, `build_success`, `indexing_tokens`
  - **주의**: `start_time`/`end_time` 절대 타임스탬프 없음 → **누적 합산**으로 start 계산
- `run_record["phase_times"]` — 단계별 소요 시간

### M-4 Cost-Efficiency 데이터 소스
- `run_record["strategy_timings"]` — `indexing_tokens.total_cost_usd` (Contextual LLM 비용)
- `ragas_df` — 전략별 품질 점수
- `latency_df` — 쿼리 수 × 평균 레이턴시 × 추정 단가로 쿼리 비용 계산

### T1. H-2: `plot_metric_violin()` 구현

**위치**: `colab_visualizer.py` line 1189 이후 삽입 (기존 `# 12. 통합 대시보드` 앞)

**설계**:
- per-sample 점수를 전략 그룹(Baseline / +Reranker / +Contextual / Both)으로 묶어 Violin 그래프 생성
- 메트릭 컬럼마다 subplot 1개 (최대 4개 서브플롯)
- seaborn `violinplot` 사용, 내부 boxplot 포함(`inner="box"`)

**함수 시그니처**:
```python
def plot_metric_violin(
    reports: Dict[str, Any],  # {strategy_name: EvaluationReport}
    metrics: Optional[List[str]] = None,  # None → 자동 선택 (최대 4개)
    top_n: Optional[int] = None,  # None → 전체
) -> None:
```

**구현 로직**:
```python
# 1. 모든 EvaluationReport.per_sample_df 합산
rows = []
for name, report in reports.items():
    df = report.per_sample_df.copy()
    df["strategy"] = name
    # 그룹 분류
    has_ctx = "Contextual" in name
    has_rerank = "FlashRank" in name or "ColBERT" in name
    if has_ctx and has_rerank:
        df["group"] = "Reranker + Contextual"
    elif has_ctx:
        df["group"] = "+ Contextual"
    elif has_rerank:
        df["group"] = "+ Reranker"
    else:
        df["group"] = "Baseline"
    rows.append(df)

combined = pd.concat(rows, ignore_index=True)

# 2. 메트릭 컬럼 자동 선택 (수치형, strategy/user_input/response 제외)
exclude = {"strategy", "group", "user_input", "response", "retrieved_contexts", "reference"}
numeric_cols = [c for c in combined.columns
                if c not in exclude and pd.api.types.is_numeric_dtype(combined[c])]
if metrics is None:
    metrics = numeric_cols[:4]  # 최대 4개

# 3. 서브플롯 생성
n = len(metrics)
fig, axes = plt.subplots(1, n, figsize=(5 * n, 5), sharey=False)
if n == 1:
    axes = [axes]

group_order = ["Baseline", "+ Reranker", "+ Contextual", "Reranker + Contextual"]
palette = {"Baseline": "#3498db", "+ Reranker": "#e74c3c",
           "+ Contextual": "#e67e22", "Reranker + Contextual": "#9b59b6"}

for ax, metric in zip(axes, metrics):
    valid_groups = [g for g in group_order if g in combined["group"].values]
    sns.violinplot(
        data=combined, x="group", y=metric, order=valid_groups,
        palette=palette, inner="box", ax=ax, cut=0,
    )
    ax.set_title(metric, fontsize=11)
    ax.set_xlabel("")
    ax.set_ylabel("Score" if ax == axes[0] else "")
    ax.set_ylim(-0.05, 1.05)
    ax.tick_params(axis="x", rotation=20)

fig.suptitle("전략 그룹별 메트릭 분포 (Per-Sample Violin)", fontsize=14, y=1.02)
plt.tight_layout()
plt.show()
```

### T3. M-3: `plot_strategy_gantt()` 구현

**설계**:
- `run_record["strategy_timings"]`에서 각 전략의 빌드 시간을 누적 합산하여 Gantt 바 생성
- X축: 경과 시간(s), Y축: 전략 레이블
- 색상: LLM 사용(Contextual) 빨강, 일반 파랑, 실패 회색
- Phase 구분선 (Pass1 시작, Pass2 시작) 점선으로 표시

**함수 시그니처**:
```python
def plot_strategy_gantt(
    run_record: dict,
    top_n: int = 40,
    show_query_time: bool = True,  # 빌드 + 쿼리 시간 구분 표시
) -> None:
```

**구현 로직**:
```python
timings = run_record.get("strategy_timings", [])

# 누적 start 시간 계산 (절대 타임스탬프 없으므로 순서 기반)
cursor = 0.0
bars = []
for t in timings[:top_n]:
    bt = t.get("build_time_s", 0)
    label = t["label"]
    has_llm = bool((t.get("indexing_tokens") or {}).get("total_tokens", 0))
    success = t.get("build_success", True)
    bars.append({
        "label": label,
        "start": cursor,
        "duration": bt,
        "has_llm": has_llm,
        "success": success,
    })
    cursor += bt

# 색상 결정
def _color(b):
    if not b["success"]: return "#bdc3c7"  # 실패: 회색
    if b["has_llm"]: return "#E45756"       # LLM: 빨강
    return "#4C78A8"                         # 일반: 파랑

fig, ax = plt.subplots(figsize=(14, max(4, len(bars) * 0.35)))
for i, b in enumerate(reversed(bars)):
    color = _color(b)
    ax.barh(b["label"], b["duration"], left=b["start"],
            color=color, alpha=0.85, edgecolor="white", linewidth=0.5)
    ax.text(b["start"] + b["duration"] / 2, i,
            f"{b['duration']:.1f}s", va="center", ha="center", fontsize=7, color="white")

ax.set_xlabel("누적 경과 시간 (s)")
ax.set_title(f"Strategy Build Gantt (총 {cursor:.1f}s)", fontsize=13)

# Phase 구분선 (phase_times 기반)
phase_cursor = 0.0
for p in run_record.get("phase_times", []):
    dur = p.get("duration_s", 0)
    if "build" in p["phase"] or "strategy" in p["phase"]:
        ax.axvline(phase_cursor + dur, color="orange", linestyle="--", linewidth=1, alpha=0.7)
    phase_cursor += dur

# 범례
from matplotlib.patches import Patch
ax.legend(handles=[
    Patch(color="#4C78A8", label="Embedding Only"),
    Patch(color="#E45756", label="+ LLM (Contextual)"),
    Patch(color="#bdc3c7", label="Failed"),
], loc="lower right")

plt.tight_layout()
plt.show()
```

### T4. M-4: `plot_cost_efficiency()` 구현

**설계**:
- X축: 전략당 총 비용(USD) = 인덱싱 비용 + 추정 쿼리 비용
- Y축: RAGAS 품질 점수 (선택 메트릭)
- 점 크기: 레이턴시 역수 (빠를수록 큼)
- 색상: 전략 그룹 (Baseline/Reranker/Contextual/Both)
- 파레토 프론티어 (저비용 고품질) 표시
- "비용 효율" 지수 = quality / (cost + ε) 상위 3개 라벨 표시

**함수 시그니처**:
```python
def plot_cost_efficiency(
    run_record: dict,
    ragas_df: pd.DataFrame,
    latency_df: Optional[pd.DataFrame] = None,
    metric: Optional[str] = None,
    cost_per_query_usd: float = 0.0000015,  # GPT-4o-mini input 토큰 추정 단가
) -> None:
```

**구현 로직**:
```python
# 1. 전략별 인덱싱 비용 추출
cost_map = {}
latency_map = {}
for st in run_record.get("strategy_timings", []):
    lbl = st["label"]
    idx_tok = st.get("indexing_tokens") or {}
    cost_map[lbl] = float(idx_tok.get("total_cost_usd", 0.0))
    latency_map[lbl] = st.get("avg_latency_ms", 0) / 1000  # s

# 2. ragas_df와 병합 (부분 문자열 매칭)
rows = []
for _, row in ragas_df.iterrows():
    name = str(row["strategy"])
    # 비용 매핑: label 부분 매칭
    idx_cost = 0.0
    lat = 0.0
    for lbl, cost in cost_map.items():
        if lbl and (lbl in name or name in lbl):
            idx_cost = cost
            lat = latency_map.get(lbl, 0)
            break
    # 쿼리 비용 추정: 레이턴시 × 쿼리 수 × 단가
    n_queries = run_record.get("num_queries", 1)
    query_cost = lat * n_queries * cost_per_query_usd
    total_cost = idx_cost + query_cost
    rows.append({**row.to_dict(), "total_cost": total_cost, "latency": lat})

merged = pd.DataFrame(rows)

# 3. 품질 메트릭 선택
if metric is None:
    numeric_cols = [c for c in merged.columns
                    if c not in {"strategy", "total_cost", "latency"}
                    and pd.api.types.is_numeric_dtype(merged[c])]
    metric = numeric_cols[0] if numeric_cols else None

# 4. 비용 효율 지수 계산 + 상위 3개 라벨
merged["efficiency"] = merged[metric] / (merged["total_cost"] + 1e-6)
top3 = merged.nlargest(3, "efficiency")

# 5. Plotly scatter
fig = go.Figure()
for group_name, color in _COLOR_MAP.items():
    gdf = merged[merged["group"] == group_name]
    if gdf.empty: continue
    fig.add_trace(go.Scatter(
        x=gdf["total_cost"], y=gdf[metric],
        mode="markers",
        name=group_name,
        marker=dict(size=12, color=color, opacity=0.8),
        text=gdf["strategy"],
        hoverinfo="text+x+y",
    ))

# 파레토 프론티어 (저비용 고품질)
pareto = _compute_pareto_front(
    merged[["total_cost", metric]].values,
    minimize_x=True, maximize_y=True,
)
if len(pareto) > 1:
    ps = pareto[pareto[:, 0].argsort()]
    fig.add_trace(go.Scatter(
        x=ps[:, 0], y=ps[:, 1], mode="lines",
        line=dict(color="gray", dash="dot", width=1.5),
        name="파레토 프론티어",
    ))

# 상위 3개 효율 전략 라벨 표시
for _, r in top3.iterrows():
    fig.add_annotation(
        x=r["total_cost"], y=r[metric],
        text=f"★ {r['strategy'][:30]}",
        showarrow=True, arrowhead=2, arrowsize=1,
        font=dict(size=9, color="#2c3e50"),
    )

fig.update_layout(
    title=f"비용 대비 품질 효율 (M-4 Cost-Efficiency) — {metric}",
    xaxis_title="총 추정 비용 (USD)",
    yaxis_title=metric,
    height=520,
    font=dict(family="NanumGothic, sans-serif"),
    legend=dict(orientation="h", yanchor="bottom", y=1.02),
)
fig.show()
```

## 주의사항

1. **H-2 Violin**: `per_sample_df`가 비어있는 경우 graceful fallback — 집계 점수만 있을 때 박스플롯으로 대체
